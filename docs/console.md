# 开发者控制台

控制台让开发者直接配置环境、理解 Agent 的执行过程，并在需要时接管调试。网页、CLI 和 Agent 共用本地管理器、配置和任务档案；网页操作不另起一份状态。本文适用于 [0.7.0 预览版](releases/v0.7.0.md) 及后续兼容版本；旧版控制台不具备这些完整入口。

## 打开与日常使用

独立安装包提供固定入口：

- Windows：双击安装目录的 `bin/Open remote-mng.cmd`。
- Linux / WSL：运行安装目录的 `bin/open-console.sh`。
- 也可以告诉 Claude Code：“打开 remote-mng 控制台。”由它调用 `rmg ui`。

固定入口会启动需要的本地管理器并打开网页。无需记住设备配置或调试 CLI。服务仅监听本机 loopback；访问链接包含本机访问凭证，不应分享。

页面分为总览、设备、任务、会话和设置。打开或刷新页面只读取本地状态；连接检查、主机公钥探测、Helper 操作、查询远端作业和发送终端输入都需要明确操作。显示的最近检查附带时间，不代表设备一直在线。

## 第一次添加设备

1. 打开“设备”，选择“添加设备”，填写名称、SSH/Telnet、地址、端口和用户名。
2. 选择认证方式：SSH Agent/系统密钥、指定私钥文件、本机临时凭据引用，或管理器进程能够取得的环境变量引用。
3. 展开高级配置，按需设置编码、超时、远端 Shell、Helper 目录、独立 SSH 传包通道及跳板/代理/登录流程。
4. 选择“预览并保存配置”，查看差异，再确认应用。这一步只修改本地配置。
5. 选择设备并“测试连接”，查看实际失败阶段和建议。需要 SSH 主机身份接入时，再按下节核对指纹。

新增、编辑、复制和删除都不会静默覆盖 Agent 的修改：保存必须与当前配置版本一致。若提示冲突，刷新最新配置，重新检查差异后再保存。编辑保留未修改的高级字段，不要求把它们重新输入一遍。

Telnet 可以使用独立 SSH 通道传包，交互登录可通过高级 `login_steps` / `login_flow` 配置。密码使用 `send_ref` 或 `send_env`，避免写在普通 `send` 字段。不同通道可以配置不同的凭据、密钥和主机身份。

### 凭据在哪里

在“设置 → 临时凭据”填写引用名称与值。保存后得到不包含密码的引用，可用于设备 `password_ref`、私钥口令 `passphrase_ref` 及登录流程 `send_ref`。

临时凭据具有明确生命周期：

- 值仅存在于本地管理器内存，不写入配置、配置备份、导出或操作审计。
- 管理器重启后值失效，已有引用仍保留；按原名称重新输入可恢复引用。
- 删除引用会使后续需要它的认证失败，不会自动中断已经认证的连接。
- 环境变量方式读取的是**管理器进程**的环境；在另一个终端临时设置变量不一定对已经运行的管理器生效。
- 私钥方式保存本机文件路径，私钥仍留在本机。认证检查显示引用和文件的可用性，不返回密码或私钥内容。

这不是持久密码保险箱，也没有宣称使用操作系统钥匙串。

### SSH 主机身份

选择需要接入的目标 SSH、跳板 SSH、传包 SSH 或传包跳板 SSH，再“读取主机指纹”。探测结果包含端点、公钥指纹和已知指纹。

**从服务器控制台、管理员提供的可信记录等独立来源核对指纹**，再明确确认保存。网络上读取到一个公钥本身不证明它属于预期服务器。已有可信密钥发生变化时，需要额外确认替换，不能用关闭严格校验解决。

信任保存使用 remote-mng 状态目录下独立的 `known-hosts` 文件，并更新对应路线的引用；不改写其他无关的用户 SSH 配置。探测结果有时限，配置或已知主机文件变化后需重新探测与预览。

## 配置交互前台

在“设置 → 交互模板”保存进入命令、前台提示符、退出命令、退出后的提示符和等待超时。提示符使用正则表达式，尽量选择能区分前台与外层 Shell 的特征。

例如某个设备需要先运行专用入口才能接受测试命令，可以把入口和退出规则保存成模板，不需要把业务软件写进工具代码。保存模板只改配置；“测试”会真实连接设备、发送进入命令并打开一个由你控制的会话。测试完成后检查输出，并明确退出前台或关闭连接。

修改模板影响新会话，已打开会话保留打开时的模板，不会悄悄切换退出规则。匹配提示符只证明看到相应输出，不等于某个测试任务通过。

## 观察、接管与归还

在“会话”选择已有会话观察输出，或选择设备、交互模板和可选初始命令，新建一个由你控制的会话。观察不会取得输入权限。

“接管输入”取得当前页面的控制租约，使旧控制凭证失效。一个时刻只有一个有效控制者；另一个页面需要明确接管。Agent 的强制接管也不能绕过人工保留状态。

控制期间可以：

- 输入文本并“发送一次”，选择是否补回车；敏感输入可单独标记脱敏。
- 查看实时输出，查询或重取上一次发送结果。
- 发送 Ctrl+C 中断当前终端前台。
- 使用模板退出命令离开交互前台，并检查退出后的提示符。
- 调整终端行列，或关闭连接。

这些操作含义不同：Ctrl+C 是发送中断字符；退出前台是发送模板配置的退出命令；关闭连接不保证远端进程结束。取消受管作业应使用任务里的对应操作。

每个页面使用随机控制标识，真正的终端控制凭证由服务器保存，不交给网页。页面定期续租；正常控制租约为 30 秒，建立交互前台时临时延长以覆盖进入等待。关闭页面、失去连接或续租过期会保留人工接管状态，**不会让 Agent 自动恢复输入**。重新打开后明确接管，再“归还控制权”，Agent 才能重新申请并读取新增输出后继续。

普通手动发送使用稳定请求 ID。响应丢失时重取同一个请求，只查询既有结果，不重新发命令。没有设置观察判据的输入显示为“已发送、结果未知”，不能把终端接受输入当作执行成功。较长的调试任务应看实际输出，或使用持久作业。

打开会话和测试交互模板也会先保存稳定请求 ID。响应丢失后重取原请求，不再次执行初始命令或进入命令；后台打开过程不会因 HTTP 连接断开而被取消。管理器重启留下的未知打开请求不会自动重开，需要先检查原会话记录。重取打开结果也不会从另一个页面手里抢回会话。

接管正在等待输出的会话时，旧观察可以被停止；已发送的命令不会因此重放，也不假定远端进程已经停止。

## 常用操作与任务透明度

在“设置 → 常用操作”保存经过确认的固定命令、说明和可选工作目录：

- `exec`：短命令，通过连接执行；可设置等待超时。
- `job`：Helper 持久作业，本地断线后仍可查询原 ID；不使用连接等待超时作为作业截止时间。

模板不进行变量插值或任意参数拼接。选择目标运行时，先展示具体端点、命令、工作目录和配置版本，确认后才提交。任务使用稳定请求 ID，重复提交同一请求返回已有任务；结果不明时先查原任务，不能为了重试生成新 ID。

Agent 可通过 CLI 的 `template list/get/run` 读取并执行同一模板。模板运行同样进入任务档案，不另建只在网页可见的任务系统。

在“任务”可以看到产物、目标、实际提交参数和命令、步骤状态、操作/会话/作业关联、输出与验证依据。来源标记描述开发者控制台或 CLI/RPC 等实际入口，不推断某个模型或人的真实身份。

查询远端状态会刷新原有作业；取消只作用于受管任务支持取消的资源，不回滚已传文件或其他终端。步骤完成不自动表示业务测试通过；输出匹配、命令退出码和业务验证应分别看待。

## Helper 与日志维护

“设备 → 连接诊断与 Helper”可以检查存储状态、明确安装/更新 Helper。安装作用于当前设备配置的 Helper 目录，普通配置保存和页面打开不会自动安装。

清理需要填写明确的原作业 ID，先预览计划，再确认应用相同计划。只清理符合条件的终态作业日志，保留作业 ID 和退出证据；活动或状态未知的作业不能当作可清理对象。任务详情也可从已关联作业生成清理预览。

“设置”中的本地单条记录日志上限控制后续本地日志保留，远端 Helper 日志容量由各设备高级配置控制。日志截断和游标缺口会被明确报告，不把缺失的历史伪装成完整输出。

## 配置导出、恢复与设备身份

配置修改前提供差异预览，实际修改自动保存备份。“设置”可导出配置、导入 JSON、查看备份列表并预览恢复。导出包含连接路线、模板和凭据引用，不包含临时凭据值；迁移后仍需准备本机私钥、环境变量或重新输入临时凭据。

导入和恢复使用同样的验证、版本检查与资源保护，不会重执行部署或任务。恢复配置也不意味着回滚远端文件或软件。

临时凭据引用需要 0.7.0 或更新的程序。配置含这些字段时，工具会阻止回退到不认识它们的旧版本；先审查并恢复兼容配置再回退，工具不会为回退自动删除你的配置。

有活动/未知资源、未结束任务或已记录远端作业时，工具会保守阻止修改设备地址、协议、用户名、Helper 目录或连接路线等身份字段，防止原 job ID 被拿到另一台服务器查询。历史受管作业即使已结束，也可能仍需查询原证据；此时应为新设备创建新名称，保留旧别名。认证引用或其他不改变设备身份的配置仍按正常验证处理。

## 离线与功能边界

离线安装继续遵守离线更新方式：总览和配置读取不访问 GitHub，也不自动探测设备；更新页面提示使用新版离线安装包。主动连接内网设备、探测 SSH 指纹及远端维护仍按你明确选择的目标执行。

控制台是个人本地管理入口，提供文本输出和受控输入，不是完整 ANSI 终端模拟器、文件编辑器、图形流程编排器或团队权限系统。普通交互连接断开后仍需新建连接，远端持久作业则按原 job ID 查询。已知凭据与标记敏感的输入会脱敏，业务输出中的其他敏感信息仍需由使用者判断后再分享。
