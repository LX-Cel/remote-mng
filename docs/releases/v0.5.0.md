# remote-mng 0.5.0 — 同一个入口完成安装和更新

**预发布版。** 本版重点降低首次使用和后续维护成本。Windows、Linux/WSL 的实际安装包已验证首装、重复运行和旧版升级；后台独立更新的 Windows 宿主限制仍需遵守，详见 [验收记录](https://github.com/LX-Cel/remote-mng/blob/main/docs/v05-validation.md)。

## 用户需要做什么

从 [README](https://github.com/LX-Cel/remote-mng#一次安装之后用自然语言) 下载对应系统的 `install.ps1` 或 `install.sh` 并运行。它自动选择版本和平台、下载并校验程序、安装 Claude Code Skill、启动并检查本地管理器。

手动更新时，**重新运行同一份脚本**。日常也可以直接对 Claude Code 说“更新 remote-mng，保留已有任务”。更新后新开 Claude Code 会话加载新版 Skill。

## 本版变化

- 独立包安装无需 Python、uv、Git 或 GitHub CLI；公开发布直接通过 HTTPS 访问，无需 GitHub 登录。
- 自动识别已有受管安装及其目录，空闲管理器由更新流程停启，程序和 Skill 一起更新。
- 保留任务、远端 job 引用及托管目录之外的 `USER.md`。已有活动、文件修改或恢复未完成时说明阻碍。
- 更新通道会被记住。当前预览期尚无支持新入口的正式版，安装器明确提示后选择兼容预览版，后续 Agent 查新继续跟随预览。
- 手动安装和更新在前台完成，只有验证成功才报告完成；Agent 原有后台更新仍保留持久进度和恢复机制。
- 为受支持的 uv 安装保存原环境快照后更新；未知 Python 环境和不兼容旧安装明确阻碍，不隐式覆盖。

## 支持范围

独立包支持 Windows x86_64、Linux x86_64；WSL 使用 Linux 包。Windows 原生 Claude Code 需要 Git Bash。Linux/WSL 安装脚本需要系统 `curl`、`awk`、Info-ZIP `unzip` 和 `sha256sum`，缺失时给出安装建议，不自动提权。

0.3 等旧管理器缺少安全停启协议，需要先核对活动并完成一次显式停止。Windows 宿主可能禁止独立进程创建，安装器会报告阻碍；本版不绕过该限制。更新不重提远端作业、不批量更新 helper，也不会重接已断开的普通交互前台。

本版保留预发布标记，不替代正式 Latest。资产来源、实际验收范围和限制随 `release-validation.json` 提供，旧版发布资产保持不变。

安装入口修订：首次公网验证发现并修正 PowerShell 对 REST 数组的枚举差异，安装脚本与摘要同步更新；本版 ZIP 和 wheel 内容未更换。已下载早期脚本的用户可重新下载根目录的 `install.ps1`。
