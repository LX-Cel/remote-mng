# remote-mng 0.6.0 — 单文件离线安装与更新

**预发布版。** 公司内网无法使用下载脚本时，现在可以先取得一个完整安装文件，再带入内网安装和更新。

- Windows：双击 `remote-mng-0.6.0-windows-x86_64-setup.exe`。
- Linux / WSL：赋予执行权限后运行 `remote-mng-0.6.0-linux-x86_64-setup.run`。

安装文件包含完整程序、Python 运行时、依赖、Claude Code Skill、网页和远端 helper。安装时不查询 GitHub 或软件源，也不要求预装 Python、uv、GitHub CLI、curl 或 unzip。默认按当前用户安装并启动本地管理器。

更新时，将**新版安装文件**带入环境后运行，保留已有任务、远端 job 引用、个人说明和适用的回退材料。重跑同版本会检查现有安装；运行旧包不会自动取得新版。

## 内网使用行为

离线安装会保存 `delivery: offline`。Agent 和网页会提示使用新版离线安装包，普通查新不会请求 GitHub，历史联网更新计划也不能绕过该选择。需要远程工作时，程序仍可连接获准的 SSH/Telnet 设备。

完整原始发行 ZIP 被原样嵌入安装器，执行前校验摘要、文件清单和平台。离线恢复缺少缓存时明确报错，不临时下载。活动前台、正在执行的操作或托管 Skill 修改仍会阻止不安全的切换。

## 支持与验证

本版支持新装和已有受管独立包升级。旧 uv/Python 环境的离线迁移暂不支持：检测后保留原环境与管理器，说明原因，不联网补依赖或擅自重装。

Windows、Linux/WSL 的真实单文件首装、重跑和官方 0.5 升级已在禁止发布查询和外网 HTTP 的测试环境通过。程序日常使用仍为稳定目录中的完整安装，只有短时安装器采用 onefile。部分 Windows 宿主限制后台进程创建，保护仍保留；本版不以安全阻碍代替安装成功。

下载、Linux 运行方式和高级选项见 [README](https://github.com/LX-Cel/remote-mng#一次安装之后用自然语言)。制品来源、平台与验收范围见 [0.6 验收记录](https://github.com/LX-Cel/remote-mng/blob/main/docs/v06-validation.md) 及随包 `release-validation.json`。旧版发布资产保持不变。
